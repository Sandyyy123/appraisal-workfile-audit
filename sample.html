02What the working code demonstrates

ControlDemonstrated behavior
Original-byte preservationThe Python ZIP exporter retains exact input bytes and verifies their recorded SHA-256 hashes before packaging.
Document-type distinctionAssessor maps and recorded plans have separate types. A pending plan stays unresolved; no substitute document is inserted.
TraceabilityAvailable documents require a source URL and retrieval timestamp. The manifest contains both available and unresolved records.
Safe exportTests reject changed bytes, duplicate IDs, unsafe paths, escaping symlinks, absent provenance and unverified zoning claims. Existing exports are preserved.

The Python demonstration exports two synthetic SVG originals and a manifest into a ZIP. This HTML demonstrates PNG cropping separately. It does not yet provide live connectors, PDF page extraction, clipboard integration, authenticated storage or an appraisal conclusion.

03Massachusetts integration assessment

Source familyInitial routeWhat must be verified
MassGIS parcelsDocumented public downloads and GIS layersMunicipality/fiscal year, identifiers and freshness. Assessor parcel boundaries are not authoritative survey boundaries.
FEMA NFHLPublished public data and mapping servicesCoverage, effective date, permitted service use and map context. A map view is not a professional flood determination.
Registry deeds and recorded plansRegistry-specific online search; assisted/manual fallbackCorrect district, recorded versus registered land, document coverage, download permissions, fees and any licensed vendor access. No universal automated registry API is assumed.
Cards, zoning and permitsMunicipality/vendor-specific evaluationWhich source has the actual document, allowed access, version/date and authoritative review. Unverified zoning stays flagged.

Source basis: MassGIS Property Tax Parcels and Interactive Property Map; Massachusetts Registry of Deeds directory; FEMA NFHL public dataset record. Public availability alone does not establish permission for bulk automation. Paid vendor licensing and manual retrieval are determined for the selected jurisdictions during discovery.
